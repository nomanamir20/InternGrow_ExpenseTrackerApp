## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.3.0 or higher)
- A Firebase project

### Setup

1. Clone the repo
```bash
   git clone https://github.com/<your-username>/InternGrow_ExpenseTrackerApp.git
   cd InternGrow_ExpenseTrackerApp
```
2. Install dependencies
```bash
   flutter pub get
```
3. Connect Firebase (Auth + Realtime Database)
4. Run
```bash
   flutter run
```
